This is a Loan Repayment Predictor demo.
In this demo, Decision Tree, Random Forest and Gradient Boosting classifier used for modelling.

- main.py contains data loading, preprocessing, train and test code.
- app.py contains streamlit code.
- There are 2 selection boxes in streamlit webapp. One for Train & Test each model and another for visualize few plots.
- loan_repay_pred.ipynb contains the Python code used for data analysis and model development, along with the corresponding outputs, visualizations and explanatory notes.
